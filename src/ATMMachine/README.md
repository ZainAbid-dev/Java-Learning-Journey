# 🏧 ATMMachine.ATM Simulation System in Java

## 📌 About the Project

This is a beginner-friendly ATMMachine.ATM Simulation System built using **Java**. I created this project as part of my Java programming learning journey to practice conditional statements, user input, and basic programming logic.

The program simulates basic ATMMachine.ATM operations through a simple, text-based interface.

## ✨ Features

* 💰 Check account balance
* 💵 Deposit money
* 💳 Withdraw money
* 🚫 Prevent invalid amounts
* ⚠️ Check for insufficient balance
* 🔄 Perform basic ATMMachine.ATM operations

## 🛠️ Technologies Used

* **Language:** Java
* **IDE:** IntelliJ IDEA
* **Concepts:** Variables, data types, `Scanner`, `if-else` statements, and user input/output

## ▶️ How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project in IntelliJ IDEA or another Java IDE.

3. Open the ATMMachine.ATM Java file.

4. Run the `main()` method.

5. Follow the instructions displayed in the console.
